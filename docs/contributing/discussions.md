# GitHub Discussions

If Discussions are enabled on this repository, use these categories:

- **Announcements** — maintainer-posted, releases and notable changes.
- **Ideas** — a feature idea that isn't yet scoped enough for an issue or
  RFC. Ideas that gain traction graduate to an issue (small) or an
  [RFC](../rfcs/README.md) (large/architectural).
- **Q&A** — "how do I..." / "why does X work this way" questions.
- **Show and Tell** — something built on top of this project.
- **Integrations** — discussion specific to a payment/storage/email
  provider integration (existing or proposed).
- **RFCs** — discussion on an open [RFC](../rfcs/README.md) PR, if the
  PR thread itself isn't the preferred venue.

Not every idea needs Discussions first — if it's already scoped and
matches something in [ROADMAP.md](../../ROADMAP.md) or the
[good first issues](good-first-issues.md) list, just open an issue or PR.
